Printable Maze Generator

Mazes in six styles, each fitted to a sheet of A4 — always solvable.

Drawing

Rotates the master light; each patch keeps its own disagreement with it, so the depth still flips. Relief is strongest near 45° and 225°, and flattens out near 135° and 315°.

Generation

Any text works. The same seed always redraws the same maze.

Options

How often the growing tree extends from the cell it reached most recently rather than from a random one on its frontier. 100% is depth-first exactly; 0% is a blob swelling outward from the start. Most of the change happens in the top half of the slider — below about 50% the texture stops moving much.

Prints too, so you can run off an answer key.
